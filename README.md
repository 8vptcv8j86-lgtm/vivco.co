# VIVCO company website

Static website for Vivco Caribbean Manufacturing, Inc. at https://www.vivco.co/.

VIVCO coordinates production readiness, manufacturer matching, sourcing, packaging, quality records and logistics through licensed manufacturing partners. Dedicated capacity in St. Croix is a longer term expansion guided by repeat demand and operating evidence.

## Run locally

Run `python -m http.server 8080` from this directory. No build or dependencies are required.

## Production

Existing Vercel project: `vivco-landing` (`prj_iV96W35GhBBwMklgKpJHgg8xcJtC`). Preserve its custom domains and access configuration. The site submits inquiries to the existing Supabase `vivco-leads` project. Its frontend key is a publishable key, not a privileged credential. A successful submission requires Supabase availability and the existing insert policy. A visible email alternative remains available if a submission cannot be confirmed.
